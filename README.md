# StopWatch Pro

A minimalistic, full-screen stopwatch Progressive Web App (PWA) designed specifically for the Apple iPad Air 11" in landscape mode.

## Features

- ⏱️ Large digital stopwatch display
- ⚫ Black background with white high-contrast digits
- ▶️ Start
- ⏸️ Pause
- 🔄 Reset (only available when paused)
- ⌨️ Keyboard shortcuts
  - Space = Start / Pause
  - R = Reset
- 📱 Optimized for iPad Air 11" (Landscape)
- 🌐 Offline support via Service Worker
- 📲 Installable as a Progressive Web App (PWA)
- 🚀 Fast and lightweight
- 🎯 Touch-friendly interface

## Display

- Automatic format:
  - `MM:SS`
  - switches to `H:MM:SS` after 60 minutes

The timer automatically scales to fill almost the entire display for maximum readability.

## Installation

Clone the repository:

```bash
git clone https://github.com/<your-account>/stopwatch-pro.git
```

Open the project directory and deploy it to any static web server.

Examples:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel

## Install on iPad

1. Open the website in Safari.
2. Tap **Share**.
3. Select **Add to Home Screen**.
4. Launch it like a native app.

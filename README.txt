STOPWATCH PRO – Installation

1. Lade den gesamten Ordner auf einen Webhoster, GitHub Pages oder Cloudflare Pages.
2. Öffne die veröffentlichte URL in Safari auf dem iPad.
3. Tippe auf Teilen → Zum Home-Bildschirm.
4. Starte die App anschließend über das neue Symbol.

Bedienung:
- START: startet oder setzt die Zeit fort
- PAUSE: hält die Zeit an
- RESET: setzt auf 00:00 zurück (nur bei pausierter Uhr)
- Leertaste: Start/Pause
- R: Reset

Hinweis:
Eine PWA muss über HTTPS oder localhost bereitgestellt werden. Das direkte Öffnen der Dateien aus der Dateien-App aktiviert Service Worker und Offline-Modus nicht zuverlässig.
